# Sleep Toggle 설계

## 요청과 범위

맥 메뉴 막대에서 시스템 전역 `SleepDisabled`를 켜고 끄는 개인용 앱이다.
사용자가 제작·설치·아이콘을 요청했고, 전환 때 macOS 관리자 인증을 사용하는 방식을 허용했다.
앱 설치·실행·자동 테스트는 기존 전역 잠자기 상태를 바꾸지 않는다.

## 동작

- AppKit 메뉴 막대 앱. Dock 아이콘과 메인 창은 만들지 않는다.
- 달 아이콘은 잠자기 허용, 해 아이콘은 전역 잠자기 차단이다. 메뉴 막대에는 글자를 표시하지 않는다.
- 메뉴에 현재 상태와 반대 상태로 전환하는 항목을 한국어로 표시한다.
- 현재 상태는 `/usr/bin/pmset -g`로 읽는다. 알 수 없거나 실패하면 상태를 추측하지 않는다.
- 전환은 macOS 기본 관리자 인증을 거쳐 `/usr/bin/pmset -a disablesleep 0` 또는 `1`만 실행한다.
- 인증 취소는 오류 경고 없이 원래 상태를 다시 표시한다. 성공 후에도 실제 상태를 다시 읽고 검증한다.
- 인증 중에는 중복 전환을 막는다. 외부 변경은 메뉴를 열 때와 15초 주기로 다시 읽는다.
- 일반 실행 시 로그인 자동 실행을 등록하며 끄는 토글은 두지 않는다. `SMAppService.mainApp` 상태를 실제 조회해 표시하고, macOS 승인이 필요하면 시스템 설정을 안내한다. 진단 명령은 등록하지 않는다.
- 앱 종료와 전역 설정은 별개다. 메뉴와 README에서 설정이 종료 뒤에도 유지됨을 알린다.
- macOS 인증 캐시, sudoers, 시스템 로그인 정책을 수정하거나 암호를 저장하지 않는다.

## 구조와 설치

Swift 6 패키지, AppKit·ServiceManagement·Foundation만 사용한다. 외부 의존성은 없다.
`SleepToggleCore`는 상태 파싱, 고정 명령, 취소 처리와 변경 후 검증을 맡는다.
`SleepToggle`은 메뉴, 상태 아이콘, 실행 중 상태와 로그인 항목을 맡는다.
빌드 스크립트는 앱 아이콘을 생성하고 `.app`을 ad-hoc 서명한다.
앱은 `~/Applications/Sleep Toggle.app`에 설치하고 실행한다.
사용자 요청으로 앱 이름은 영어이며, Finder/Spotlight에서 재실행하면 메뉴를 연다.
이 도구는 ERP와 독립된 새 소스 디렉터리에서 작업한다.

## 검증 기준

- 모의 실행기로 상태 0/1, 잘못된 출력, 권한 오류, 인증 취소, 변경 후 불일치를 테스트한다.
- 실제 앱 빌드와 코드 서명 검증, 읽기 전용 `--status`, 메뉴 구성 `--smoke-test`를 실행한다.
- 앱 실행 뒤 메뉴 막대 등록과 실제 표시 상태를 확인한다.
- 자동 검증은 전역 설정을 변경하거나 관리자 인증을 띄우지 않는다.
- 실제 클릭 후 관리자 인증은 사용자의 첫 토글에서 이루어진다. 검증 한계를 명시한다.
